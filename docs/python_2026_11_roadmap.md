# Python強化月間 ロードマップ

- **期間**：2026年11月1日〜30日
- **方針**：毎日1問を基本に、AIに実装させず自力でコードを書く
- **目安**：1日30〜60分（必要なら延長せず未完成として記録）
- **最終目標**：仕様からデータ構造・関数を考え、ドキュメントを参照しながら100〜200行程度の小規模プログラムを独力で完成させる

## 現状と課題

2026年10月のアクセスログ解析課題を、AIによるコード生成なしで約90分かけて実装した。

- **できたこと**：`split()`による分解、辞書による頻度集計、条件分岐、最大値探索、エラーメッセージを読んでの修正
- **苦戦したこと**：辞書への値の追加・更新など、Pythonの言語仕様・データ構造の操作
- **暫定的な分析**：解法の大枠よりも、考えた処理をPythonで正確に記述することが主なボトルネック。複雑なアルゴリズムの能力はまだ未検証
- **今後の課題**：言語習熟、境界条件の確認、独力で設計・実装する経験の蓄積

## 1日1問の進め方

週5日は新規問題、週1日は弱点を狙った類題、週1日は過去問の再実装・復習を基本とする。実力に応じて調整する。

1. 要件・入力例・境界条件を読む。
2. 必要な処理とデータ構造を自分で考える。
3. **AIに完成コードを書かせず**、自分で実装する。
4. 公式ドキュメントを調べ、エラーを読み、自力で修正する。
5. テストして提出し、AIにレビューしてもらう。
6. 指摘事項を修正し、弱点を記録する。

### AI使用ルール

- **利用可**：課題出題、Pythonの概念・仕様の説明、段階的ヒント、コードレビュー、進捗分析
- **原則禁止**：課題の途中で完成コードを生成させること
- **補足**：公式ドキュメントや検索の利用は可。短い独立したサンプルによる仕様確認も可

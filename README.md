# Python Code from Spec

**仕様からPythonプログラムを自力で設計・実装する能力を鍛える、30日間のプログラミングトレーニング。**

*A 30-day challenge to improve independent Python implementation skills.*

## 概要

このリポジトリは、文章で与えられた仕様から、AIによるコード生成に依存せずにPythonプログラムを設計・実装・デバッグする能力を鍛えるための学習記録です。

AIが生成したコードを理解するだけでなく、初見の問題に対して自分で処理方針を考え、動作するコードを書けるようになることを目指します。

## 目標

- 仕様を読み、実装に必要な処理へ落とし込む
- 問題に合ったデータ構造とアルゴリズムを選ぶ
- Pythonの基本機能を自在に使いこなす
- 境界条件を考慮したテストを作成する
- エラーの原因を調べ、自力で修正する
- 読みやすく保守しやすいコードを書く

## 学習の進め方

1. **仕様の確認**：入力・出力・制約・境界条件を整理する
2. **設計**：処理の流れとデータ構造を考える
3. **実装**：まずは自力でコードを書く
4. **テスト**：正常系だけでなく境界条件も検証する
5. **レビュー**：問題点と改善の余地を確認する
6. **修正・振り返り**：原因を理解して修正し、次の課題に生かす

### AIの利用方針

AIは**コードの代筆者ではなく、出題者・指導者・レビュアー**として利用します。

- 課題の出題と仕様の提示
- Pythonの言語仕様や概念の説明
- 必要に応じた段階的なヒント
- 提出コードのレビューと弱点分析

課題の実装は自分で行い、取り組みの途中で完成コードを受け取らないことを原則とします。AIのヒントやレビューを受けて修正した場合は、独力で完成した場合と区別して振り返ります。

## 評価方法

| 評価項目 | 配点 |
| --- | ---: |
| 正確性・要件充足 | 40 |
| アルゴリズム・処理設計 | 25 |
| 可読性・保守性 | 20 |
| 境界条件・例外処理 | 15 |
| **合計** | **100** |
